# Sistema de Inventario Hospital San Gabriel

Proyecto fullstack desarrollado para la gestión de inventario clínico.

## Tecnologías utilizadas
- **Frontend:** Angular 22 (con Signal Forms y Tailwind CSS)
- **Backend:** FastAPI (Arquitectura por capas)
- **Base de Datos:** SQL Server (Procedimientos almacenados y transacciones)

## Instrucciones de Ejecución
1. **Backend:** Ir a la carpeta `backend`, activar el entorno virtual y ejecutar `uvicorn app.main:app --reload`.
2. **Frontend:** Ir a la carpeta `frontend`, instalar dependencias con `npm install` y ejecutar `npm start`.
